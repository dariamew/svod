# Свод: фирменные материалы

- `logo.png` — знак с прозрачным фоном.
- `icon-*.png` — иконки приложения для разных размеров.
- `og.png` — карточка ссылки, 1200 × 630 px.
- `logo-source.png`, `og-source.png` — исходные сгенерированные изображения.

Подготовка размеров: `node scripts/prepare-brand.mjs` из корня проекта.
