# Свод

Нормализация прайс-листов и сравнение цен поставщиков. React, TypeScript, shadcn/ui, Express, SQLite.

## Запуск

Node.js 24 или новее:

```powershell
npm ci
npm run build
npm start
```

Адрес по умолчанию: http://127.0.0.1:3001. Повторный запуск — `npm start` или `run-local.cmd`.

Разработка: `npm run dev`. Клиент работает на порту 5173, API — на 3001.

## Работа с прайсами

1. Создайте аккаунт.
2. Загрузите файл, укажите поставщика и его оценку надёжности.
3. Сопоставьте колонки. Обязательны наименование и цена.
4. Проверьте строки и подтвердите загрузку.
5. Сравните предложения, сохраните выбор или выгрузите CSV.

Регистрация создаёт пустой аккаунт. Каталог формируется из подтверждённых загрузок. Надёжность задаётся пользователем; приложение не присваивает оценку автоматически.

## Форматы и расчёты

- CSV: UTF-8 или Windows-1251.
- Excel: `.xlsx`, выбор листа. Для формул используется сохранённый результат Excel.
- PDF: текстовая таблица. Скан следует предварительно распознать.
- Лимиты по умолчанию: 15 МБ, 10 000 строк, 80 колонок, 100 страниц PDF.

Цены в рублях. Цена со скидкой округляется до копеек. НДС принимается из исходной цены; доставка не учитывается. Приложение сопоставляет нормализованные наименования и единицы измерения, сохраняя характеристики товара. Разные названия одного товара исправляются перед загрузкой.

Разница с медианой рассчитывается для корзины по одной единице каждого товара. Фильтры применяются к предложениям и статистике. При одинаковой цене первым показан поставщик с большей оценкой надёжности.

Новый прайс заменяет активные позиции выбранного поставщика. История загрузок сохраняется, выбор заменяемых предложений очищается. Скидка поставщика действует при следующей загрузке, когда строка файла не содержит собственной скидки.

## Настройки

Сервер принимает переменные окружения. Значения по умолчанию находятся в `shared/config.mjs`.

| Переменная | Назначение |
| --- | --- |
| `HOST`, `PORT` | Адрес и порт сервера |
| `CLIENT_PORT` | Порт клиента при разработке |
| `DATA_DIR` | Каталог SQLite |
| `ALLOWED_ORIGINS` | Разрешённые origins через запятую |
| `UPLOAD_MAX_MB` | Размер файла |
| `IMPORT_MAX_ROWS`, `IMPORT_MAX_COLUMNS` | Размер таблицы |
| `PDF_MAX_PAGES` | Число страниц PDF |
| `SESSION_DAYS` | Срок сессии |
| `PREVIEW_MINUTES` | Срок предпросмотра |
| `AUTH_MAX_ATTEMPTS`, `AUTH_WINDOW_MINUTES` | Ограничение попыток входа |
| `PUBLIC_URL` | Публичный URL для абсолютных OG-метаданных |

База: `data/svod.sqlite`. Резервная копия — каталог `data` после остановки сервера. Авторизация использует scrypt и HttpOnly-cookie. API проверяет владельца данных. Сервер по умолчанию слушает loopback-адрес.

## Оформление

Айдентика: Свод. Основной цвет `#007DAF`, акцентный фон `#E8F5FC`, рабочий фон `#F3F6F9`, текст `#243442`. Inter Variable с кириллицей поставляется вместе с приложением.

Типографика: заголовок 26/34 px, заголовок блока 15/22 px, основной текст 14/21 px, таблицы 13/20 px, подписи 12/18 px. Основной шаг отступов — 4 px. Цвета определены в CSS-токенах.

Файлы айдентики: `public/brand/logo.png`, `public/favicon.ico`, `public/brand/icon-*.png`, `public/brand/og.png`. OG — 1200×630 px. Исходные изображения сгенерированы встроенным imagegen. Подготовка размеров: `node scripts/prepare-brand.mjs`.

Промпты: геометрический голубой знак из строк таблицы для Свод; белая OG-карточка с тем же знаком, названием «Свод» и подписью «Сравнение прайс-листов». Точные спецификации — `design/image-prompts.md`.

## Проверки

```powershell
npm test
npm run build
```

Проверяются форматы, числа, скидки, группировка товаров, медианы, авторизация, изоляция аккаунтов, обновление каталога и сохранение данных после перезапуска. Тесты создают входные файлы и отдельную временную базу, которая удаляется после проверки.
